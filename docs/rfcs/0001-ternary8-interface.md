# RFC 0001 삼진 내적 회로의 동작 규약

- Status: Draft — 팀의 문서 승인 상태이며 구현 시험 결과가 아니다.
- 적용 대상: 삼진 내적 코어와 이를 연결하는 FPGA·테스트벤치.
- 근거: 김태완, 「My Chip 설계 실습 안내서」(2026.10.18), 공통 인터페이스 6~7쪽, 삼진 내적 20~23쪽.

안내서의 팀 3은 주제 번호이며 저장소 식별자는 Circuit Team 05로 유지한다. 가이드에 이미 명시된 요구사항을 아래에 정리한다. 새 팀 규칙은 RFC 0002에서 다룬다. 규약의 승인과 구현의 시험 통과는 별개다.

## HW01 연산과 구현 제약

- `y = Σ wi·ai`, i는 0부터 7까지다.
- ai는 2의 보수 signed 8비트 정수 −128~127이다.
- 가중치는 `00`=0, `01`=+1, `10`=−1, `11`=불법 코드로 해석한다.
- 결과는 signed 12비트이며 합법 입력의 범위 −1024~+1024를 정확히 표현해야 한다.
- −128에 −1을 곱한 항은 +128이어야 한다. 8비트에서 먼저 부호를 반전해 값을 잃어서는 안 된다.
- 가이드의 12비트 가감산 경로 하나를 순차 재사용하는 제약을 따른다. 일반 곱셈기, SRAM, bias, activation 함수는 이번 구현 범위에 넣지 않는다.
- 실제 합성 자원 공유 여부는 별도 합성 결과로 확인한다. RTL에서 가산기 모듈이 하나라는 사실만으로 이 제약을 통과했다고 판정하지 않는다.

## HW02 입력 수신

- 단일 외부 `CLK`의 상승 에지 직전 `IN_VALID && IN_READY`가 1일 때만 `IN[3:0]` 한 조각을 수신한다. 초기 목표 클록은 10 MHz다.
- 한 바이트는 하위 4비트 다음 상위 4비트로 전송한다.
- 순서는 W0, W1, a0~a7이며 총 10바이트, 20조각이다. 별도 START·opcode는 없다.
- W0의 bit1:0부터 w0, w1, w2, w3을, W1의 bit1:0부터 w4, w5, w6, w7을 담는다. 가중치 하나는 2비트다.
- 대기 중인 송신자는 수신되지 않은 데이터와 `IN_VALID`를 유지해야 한다. 입력 사이에 유효 신호가 없는 공백을 허용한다.
- 완성된 바이트는 내부 계산에 정확히 한 번 전달해야 한다. 내부 버블의 구체적인 길이는 구현 선택이다.

## HW03 출력과 응답 시간

- 출력 데이터 16비트의 bit11:0은 y, bit12는 불법 가중치 오류, bit15:13은 000이다.
- 하위 4비트부터 네 조각을 연속 전송한다. `OUT_VALID=1`인 각 상승 에지에서 수신한다.
- `OUT_READY`는 없다. 수신자는 출력을 정지시킬 수 없다. `OUT_VALID=0`인 `OUT` 값은 해석하지 않는다.
- 마지막 입력 조각을 수신한 에지부터 32클록 이내에 첫 출력 조각을 수신해야 한다.
- 출력 중 `IN_READY=0`이며 마지막 출력 조각을 보낸 뒤에만 다음 작업을 받는다.
- 마지막 항과 마지막 가중치의 오류까지 결과에 포함해야 한다.

## HW04 오류와 작업 경계

- 불법 가중치 `11`의 항은 0으로 계산하고 오류 플래그를 1로 설정한다. 나머지 항은 계속 계산한다.
- 오류는 해당 작업 동안 유지한다. 새 작업에서 이전 합과 오류가 다음 결과에 남지 않게 초기화한다.
- 초기화 시점은 새 W0 바이트 처리 시점으로 한다. 가이드의 FSM 지침에 따른다.

## HW05 리셋과 시험기

- `RST_N`은 동기식 active-low다. 0인 상승 에지에서 초기화하며 다른 수신·계산·출력보다 우선한다.
- 리셋은 최소 네 번의 상승 에지 동안 유지한다. 미완료 바이트·작업·출력을 폐기한다.
- 하강 에지에서 리셋을 해제하고 두 클록 후 W0부터 새 작업을 보낸다.
- 시험기는 입력을 하강 에지에 갱신하고 상승 에지에서 수신 여부를 판단한다.
- 리셋 중 `IN_READY=0`이라는 추가 보장은 규정하지 않는다. 리셋 에지를 데이터 수신으로 세지 않는다.

## HW06 RTL 합격 조건

- 단일 항 256 입력 × 4 코드 = 1,024조합을 검사한다.
- 합법 가중치 6,561조합을 고정 경계 입력 패턴과 비교한다.
- ±1024, 모두 127·−128, 상쇄, 각 항 위치, 마지막 항만 유효한 사례를 검사한다.
- 각 위치의 불법 코드, 작업 간 오류 초기화, 결과 비트 배치를 검사한다.
- 고정 seed의 무작위 10,000작업과 입력 공백을 검사한다.
- 가중치 사이·입력·출력 중 리셋, 정상 복구와 32클록 응답 상한을 검사한다.
- 독립 Python 정답 모델과 외부 출력의 비트 단위 일치를 판정한다. 아직 실행하지 않은 시험은 통과로 기록하지 않는다.

## 적용 범위와 근거의 제한

이 문서는 RTL 기능 계약이다. P&R, STA, DRC/LVS, 추출 후 검증과 제출 규정 전체를 대신하지 않는다. 실물 목표는 MPW 4차 서비스 제출·제작 후 FPGA 연결 시험이다. 가이드 원문은 현재 팀이 공유한 PDF이며, 저장소에 배포 가능한 원문 링크는 아직 없다. 제출 시 최신 공식 서비스 규정과의 대조가 필요하다.
