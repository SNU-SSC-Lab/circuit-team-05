# NSPL 공정 검증 자료·지원 요청문

아래 본문을 담당자에게 전달한다. 작성만 했으며 발송하지 않았다. 공개 키트에서 확보한 원본은 다시 요청하지 않는다.

---

안녕하세요. SNU SSC 회로 5팀 삼진 내적 프로젝트에서 검증을 맡고 있는 도재겸입니다.

MyChip 4차 제출을 준비하며 `NSPL_05CMOS_PDK_260820`으로 RTL 합성·배치배선·GDS 생성과 검사를 자동화하고 있습니다. 코어 LVS와 기능 시험은 실행했으며, 전체 공정 검사와 최종 핀맵을 확정하기 위해 아래 사항의 확인·지원을 부탁드립니다.

공개 키트에서 이미 확보한 자료는 다음과 같습니다.

- 표준셀 Liberty·LEF·GDS·CDL과 공정 소자 모델
- Calibre/Assura DRC·LVS·PEX 규칙, ITF·TLUplus·QRC·MIPT 등 RC 자료
- `ETRI_NSPL_GPIO_250610`의 GDS·OpenAccess 원회로와 `MPW_PAD_28pin` 배치

**1. 적용할 공정·검증 기준**

260820 키트와 포함된 v1.1 검증 deck을 이번 제출에 그대로 적용하면 되는지, 추가 수정본이 있는지 확인 부탁드립니다. 최종 제출에 인정되는 도구·deck·검사 범위와 오픈소스 검사 결과를 사용할 수 있는 범위도 알고 싶습니다. 필요하다면 최종 GDS의 공식 DRC/LVS/PEX를 지원받을 수 있는 절차도 안내 부탁드립니다.

**2. GPIO 원회로 내보내기와 사용 조건**

현재 사용하는 `PIC`, `POB4`, `PVDD`, `PVSS` 및 필요한 하위 셀의 **원회로에서 내보낸 SPICE 또는 CDL**을 받을 수 있을까요? 원회로 `sch.oa`는 키트에 있으나 현재 환경에서 검증된 텍스트 netlist로 내보내지 못했습니다. 전체 계층의 include 파일, 핀 순서, 소자 모델명·파라미터와 내보내기 설정이 함께 있으면 도움이 됩니다.

또한 GPIO의 전원·입출력 전압, 구동 능력·허용 부하, 미사용 입력/enable 처리와 지연 자료를 부탁드립니다. GPIO Liberty가 없다면 사용 가능한 특성화 결과나 기준 SPICE 시험 조건이 있는지 알고 싶습니다. GDS 추출본을 기준 회로로 재사용하지 않고 독립적인 원회로와 비교하려는 목적입니다.

**3. 배선 RC의 기준 결과**

NSPL용으로 검증된 OpenRCX 규칙과 정확도 확인 기록이 있다면 공유 부탁드립니다. 공개 키트의 QRC `profiles/*.dat*`·`models/*.net_ascii`도 확인했습니다. 이 자료의 열·단위·패턴 대응을 설명하는 문서나 OpenRCX로 재사용한 방법이 있다면 먼저 그 자료를 부탁드립니다. 현재는 이를 검증된 기준 SPEF로 변환하는 방법을 확인하지 못했습니다.

기존 자료를 재사용하기 어렵다면, 저희가 준비할 작은 배선 패턴의 DEF/GDS·연결 정보를 기준 도구로 한 번 추출하여 **SPEF와 실행 조건**을 받을 수 있는지 문의드립니다.

사용한 deck·도구 버전, 공정 corner, 온도·단위, via/결합 용량·셀 내부 포함 범위를 함께 확인하고 싶습니다. 우선 제공 가능한 corner부터 시작해도 됩니다. 이후 이 결과를 기준으로 오픈소스 모델을 만들고 오차를 대조하려 합니다. 매 PR마다 상용 도구를 실행해 달라는 요청은 아닙니다.

**4. DRC 기준 예제·해석 확인**

있다면 정상/위반 예제 GDS와 Calibre 또는 Assura의 규칙별 결과를 부탁드립니다. 특히 well 전위 구분, tap 거리, 넓은 금속, ESD/guard ring 및 seal ring의 공식 예외 적용 방법이 필요합니다. 원본에 명시된 예외만 적용하고 별도 근거 없이 검사를 끄지 않으려 합니다.

대조 과정에서 아래 차이도 발견하여 적용 기준을 확인하고 싶습니다.

- Calibre의 `OFFGRID_FVTN`은 본문에서 `FVTP`를 검사하고, Assura는 FVTN/FVTP를 각각 검사합니다. 의도한 층과 적용할 수정본이 있을까요?
- `13.PAD.A`의 Calibre 본문은 최소 폭 80µm를 검사하며 min/max라는 주석과 차이가 있습니다. Assura에는 `geomContactCheck`를 사용하는 별도 식이 있습니다. 허용 pad opening 치수와 두 식의 적용 기준을 확인 부탁드립니다.
- 금속 antenna 항목 `8.MET1.ANT`·`10.MET2.ANT`·`12.MET3.ANT`는 Calibre DRC 본문에서 주석 처리되어 있지만 Assura에서는 실행 식을 확인했습니다. Calibre의 별도 ANT deck을 포함해 최종 적용할 검사 묶음을 확인 부탁드립니다.

**5. 최종 핀맵과 본딩 조건**

공통 신호는 CLK·리셋·handshake를 포함해 13개입니다. 현재 실험 조립본은 나머지 pad를 전원/접지로 연결했으나 본딩·외부 접속을 포함한 최종 사용 핀표는 미확정입니다.

교육 과제의 전원·접지 포함 25핀 이하 조건을 적용할 때, 필수 전원/접지 pad의 종류·개수·본딩 조건과 미사용 pad/GPIO의 처리 방법을 확인 부탁드립니다. 내부 pad-ring 연결, 실제 본딩, 외부 사용 중 무엇을 기준으로 사용 핀을 세는지도 알고 싶습니다. 필수 전원 연결이나 ESD 구조를 임의로 제거하지 않고 최종 핀맵을 확정하려 합니다.

공유 가능한 자료나 기존 가이드의 위치만 알려주셔도 해당 자료부터 확인하겠습니다. 감사합니다.
